# react-native-true-image

A single-layer, cache-key-stable image component for React Native

## Installation


```sh
npm install react-native-true-image
```


## Usage


```js
import { TrueImageView } from "react-native-true-image";

// ...

<TrueImageView color="tomato" />
```
